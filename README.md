# 🌿 Plant Test - Interface Naturelle & Responsive

Une vitrine moderne dédiée à l'univers de la botanique, conçue avec les dernières technologies web pour offrir une expérience utilisateur fluide et apaisante.

## 🚀 À propos du projet
**Plant Test** est un projet d'interface utilisateur (UI) explorant l'utilisation de **Tailwind CSS v4**. L'objectif est de créer un catalogue de plantes interactif, mettant en avant le minimalisme et la performance.

Ce projet sert de démonstration pour l'intégration de designs modernes et de workflows optimisés avec les outils de développement actuels.

## 🛠️ Technologies
- **Front-end :** HTML5, CSS3 (Modern features)
- **Framework CSS :** [Tailwind CSS v4](https://tailwindcss.com/)
- **Build Tool :** @tailwindcss/cli
- **Gestionnaire de paquets :** npm

## ✨ Fonctionnalités
- [x] **Tailwind CSS v4 :** Utilisation de la nouvelle architecture CSS-first.
- [x] **Performance :** Styles optimisés et compilation ultra-rapide via CLI.
- [x] **Responsive Design :** Adapté à tous les écrans (Mobile, Tablette, Desktop).
- [ ] **Catalogue Interactif :** (À venir) Galerie de plantes avec filtres dynamiques.

## 📦 Installation et Utilisation

### Prérequis
- [Node.js](https://nodejs.org/) (version stable recommandée)
- npm

### Installation
```bash
# Cloner le projet
git clone https://github.com/russel-fullstack/tailwind-plant.git

# Accéder au dossier
cd "plant test"

# Installer les dépendances
npm install
```

### Développement
Pour lancer la compilation du CSS en temps réel et surveiller les changements :
```bash
npm run watch
```

## 📈 Référencement & Optimisation
Pour assurer un meilleur référencement (SEO), le projet suit ces principes :
- **Sémantique HTML :** Utilisation rigoureuse des balises `<header>`, `<main>`, `<section>`, etc.
- **Vitesse :** Chargement minimal de ressources grâce à l'optimisation native de Tailwind 4.
- **Accessibilité :** Respect des contrastes et navigation facilitée.
